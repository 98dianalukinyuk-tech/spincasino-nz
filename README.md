# Spin Casino — New Zealand physical venue website

## Positioning

A land-based entertainment venue balancing warm hospitality, intimate gaming rooms and a relaxed coastal sensibility.

## Visual system

- Concept: Volcanic charcoal, fern green, warm amber and flowing architectural edges.
- Logo: A circular current crossing a vertical doorway, suggesting motion, coast and arrival.
- Palette: #07100e, #12221d, #3d8b70, #d98b45, #f1eee5, #a8c6b7
- Typography: Archivo for headings, Source Sans 3 for body copy
- Locale: en-NZ
- Currency context: NZD
- Timezone: Pacific/Auckland

## Run locally

Open `index.html` in a modern browser. No build step or server is required.

## Confirmed-data workflow

The source intentionally leaves physical address, phone, email and operating hours unset because no operator-verified values were supplied. Add those values to `data.js` only after documentary verification, then publish them consistently in the visit pages, footer and structured data.

Before public release, verify:

1. Permission to use the brand name and logo.
2. The operator, physical address and venue licence.
3. Local legal age, accepted ID and advertising rules.
4. Opening hours, transport, parking and accessibility.
5. Game types, dining services and event listings.
6. Responsible gaming and self-exclusion procedures.
7. Privacy controller details and any form-processing endpoint.

The site is strictly visit-focused. It provides no remote games, gaming account, payment flow or wagering functionality.
